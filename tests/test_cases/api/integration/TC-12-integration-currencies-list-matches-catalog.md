### TC-12: Список валют совпадает с конвертацией в каталоге

**Тип:** Интеграционный
**Приоритет:** Средний
**Предусловия:** Backend запущен, курсы валют загружены

**Шаги:**
| # | Запрос | Ожидаемый результат |
|---|--------|---------------------|
| 1 | GET /api/v1/currencies | HTTP 200, получить массив `items` с кодами валют |
| 2 | Для каждой валюты: GET /api/v1/catalog?currency={code} | HTTP 200, `currency` совпадает с переданным `code`, `items[0].price.currency` совпадает с `code` |
| 3 | Проверить полноту списка | Коды валют содержат: USD, EUR, RUB, GBP, UAH, TRY, CNY, JPY, CAD, CHF (всего 10) |

**Постусловия:** Нет
