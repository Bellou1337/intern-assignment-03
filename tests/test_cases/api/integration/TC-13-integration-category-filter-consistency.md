### TC-13: Категории из каталога совпадают с фильтрацией по категории

**Тип:** Интеграционный
**Приоритет:** Средний
**Предусловия:** Backend запущен, каталог синхронизирован

**Шаги:**
| # | Запрос | Ожидаемый результат |
|---|--------|---------------------|
| 1 | GET /api/v1/catalog | HTTP 200, получить `categories` — массив с `slug` и `title` |
| 2 | Для каждой категории: GET /api/v1/catalog?category={slug} | HTTP 200, `meta.category` = переданный slug, все `items[i].category.slug` совпадают с переданным |
| 3 | Проверить totalProducts | Сумма `meta.totalProducts` по всем категориям >= `meta.totalProducts` без фильтра |

**Постусловия:** Нет
