### TC-11: Список языков совпадает с поддерживаемыми в каталоге

**Тип:** Интеграционный
**Приоритет:** Средний
**Предусловия:** Backend запущен, каталог синхронизирован, переводы загружены

**Шаги:**
| # | Запрос | Ожидаемый результат |
|---|--------|---------------------|
| 1 | GET /api/v1/languages | HTTP 200, получить массив `items` с кодами языков |
| 2 | Для каждого языка из списка: GET /api/v1/catalog?lang={code} | HTTP 200, `language` совпадает с переданным `code` |
| 3 | Проверить полноту списка | Коды языков содержат: en, ru, de, fr, es, it, pt, tr, uk, zh (всего 10) |

**Постусловия:** Нет
