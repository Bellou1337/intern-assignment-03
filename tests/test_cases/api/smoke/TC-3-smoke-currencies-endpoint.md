### TC-3: Получение списка поддерживаемых валют

**Тип:** Smoke
**Приоритет:** Критический
**Предусловия:** Backend запущен, каталог синхронизирован

**Шаги:**
| # | Запрос | Ожидаемый результат |
|---|--------|---------------------|
| 1 | GET /api/v1/currencies | HTTP 200, `items` — массив, каждый элемент содержит поля `code` (string), `name` (string), `symbol` (string), `isSourceCurrency` (boolean) |
| 2 | Проверить наличие базовой валюты | В массиве `items` есть элемент с `code="USD"` и `isSourceCurrency=true` |

**Постусловия:** Нет
