### TC-2: Получение списка поддерживаемых языков

**Тип:** Smoke
**Приоритет:** Критический
**Предусловия:** Backend запущен, каталог синхронизирован

**Шаги:**
| # | Запрос | Ожидаемый результат |
|---|--------|---------------------|
| 1 | GET /api/v1/languages | HTTP 200, `items` — массив, каждый элемент содержит поля `code` (string), `name` (string), `isSourceLanguage` (boolean) |
| 2 | Проверить наличие базового языка | В массиве `items` есть элемент с `code="en"` и `isSourceLanguage=true` |

**Постусловия:** Нет
